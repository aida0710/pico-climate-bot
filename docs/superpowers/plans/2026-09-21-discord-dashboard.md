# 実装・検証計画

1. 接続中Picoをバックアップし、既存センサーと停止対策を保持する。
2. CRC付き循環履歴とMicroPython専用PNG描画を実装・単体検証する。
3. Discord RESTクライアントに同一投稿編集、分割送信、重複防止、応答サイズ上限を実装する。
4. 測定ループを統合し、通信断でも記録、初期時計では公開しないことを検証する。
5. 私有設定を安全に転送し、Pico単体で実投稿・再起動後編集・通常5分周期の編集を確認する。
6. 実測画像を目視確認し、テスト結果・実機結果・未検証の長期稼働をREADMEへ記録する。

作業元は ~/projects/codex/pico-sensor。パッケージのグローバル追加なし。通常反映は既存CLI、秘密情報はGit管理外。
