# Pico単体のDiscord温湿度Bot

Pico W / MicroPythonでセンサー測定、7日間の保存、PNG生成、Discord送信まで実行する。Bot「お家管理」はユーザー指定の `bot` チャンネルへ1件だけ投稿し、以降は同じ投稿と画像を更新する。Macや常設サーバーは不要。公開キー・Gateway接続は使わない。

測定間隔は約5分。CRC付き12バイトの固定長レコードを2016件の循環ファイルに保存し、再起動時に有効レコードを走査する。未同期の初期時計では保存・投稿しない。同期後の通信断でも測定履歴を残す。DHT11の温度と湿度を480×272 PNGの別パネルへ描画し、未取得期間・15分超の欠測を補間しない。画像はPico内で作り、1 KBずつmultipart送信する。

投稿IDと初回作成試行を原子的に保存し、応答喪失時は自分のマーカー付き投稿を照合する。解決不能なら重複投稿を避けて待つ。編集では画像を置換、メンションは無効、API応答は16 KB以内。429で待機延長、404で追加投稿しない。Bot設定時は旧Webhookを使用しない。

既存の8秒ウォッチドッグ、Wi-Fi再接続、HTTPタイムアウト、ticks_diffによる時刻差計算、USBバックアップと照合を維持する。トークンは本体configと非公開credentialsだけに保持し、ログやGitには入れない。

検証は循環・破損・時計・欠測、PNG構造とメモリ、POST/PATCH/再起動/応答喪失/429/404を自動化。実機で通常周期の同じ投稿ID更新と画像表示を確認する。数ヶ月の連続稼働を短時間試験で保証しない。
